# Text Case Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** an "Aa" menu on the slide text bar that changes the selected text to UPPERCASE, lowercase, Sentence case or
Capitalize Each Word.

**Architecture:** a pure function decides each character's case from a whole paragraph's text; a Tiptap chain command
rewrites the changed text pieces in place (marks kept); `TextFormatToolbar` runs it through `formatChain` on every
picked text.

**Tech Stack:** Tiptap / ProseMirror, lucide-react, Node's test runner.

**Spec:** `docs/superpowers/specs/2026-11-25-text-case-design.md`

## Global Constraints

- No saved-shape change, no `DATA_VERSION` bump, no migration.
- Design system: reuse `ToolPanelButton` and Lucide icons; no new colors.
- `textCase.ts` may only import types (so `npm test` can load it).

## Review Focus

- A word split by bold ("**H**ello") under Capitalize Each Word → "Hello", not "HEllo".
- Apostrophes: "don't" → "Don't"; curly ’ too.
- Selection starting mid-paragraph under Sentence case → judges by the text before it, not the selection's start.
- Line break (hard break) mid-sentence → no capital after it under Sentence case.
- Nothing changes (already upper) → no transaction step (no undo entry, no save).

### Task 1: case rules (`src/lib/textCase.ts`)

**Interfaces — Produces:**
- `type TextCase = "upper" | "lower" | "sentence" | "title"`
- `TEXT_CASES: { value: TextCase; label: string }[]` (labels: "UPPERCASE", "lowercase", "Sentence case",
  "Capitalize Each Word")
- `changeCase(text: string, kind: TextCase): string[]` — one output string per input character (UTF-16 unit),
  so positions map 1:1 even when `toUpperCase` grows a letter.
- `applyTextCase(tr: Transaction, kind: TextCase): boolean` — rewrites the selection (whole doc when empty).

- [ ] Tests in `src/lib/textCase.test.ts`: `changeCase(...).join("")` for "hello WORLD" upper/lower; sentence
  "hELLO. how ARE you? fine" → "Hello. How are you? Fine"; title "don't STOP the bus" → "Don't Stop The Bus"; title
  with ’; a "\n" (hard break stand-in) mid-sentence keeps lowercase after it; "ß" upper → ["SS"].
- [ ] Run `npm test` → fails (no module).
- [ ] Implement. `applyTextCase`: for each textblock touching the range, `text = block.textBetween(0, size, "\n", "\n")`
  (hard break = 1 char), `cases = changeCase(text, kind)`; collect each text node in the range with its slice; go
  from last to first, replace with `schema.text(newText, node.marks)` only when different. Return true.
